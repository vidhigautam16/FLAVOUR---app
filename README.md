# 🍽️ FLAVOUR

A modern and responsive food delivery web application built with React, TypeScript, Vite, and Tailwind CSS.

## 🚀 Features

- Responsive UI
- Food menu browsing
- Add to cart
- Fast performance
- Modern design

## 🛠️ Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Shadcn UI

## ▶️ Run Locally

```bash
git clone https://github.com/vidhigautam16/FLAVOUR---app.git
cd FLAVOUR---app/flavour--main
npm install
npm run dev
```
